# Diksha-Portfolio

A modern, elegant, and fully responsive personal portfolio website built with HTML, CSS, and JavaScript.

Inspired by minimalist design principles and enhanced with a custom Rose Glass aesthetic, the portfolio is designed to showcase projects, technical skills, and professional information while providing a smooth and engaging user experience.

---

## ✨ Features

- 🌹 Custom Rose Glass design system
- 🌙 Light & Dark Mode
- 📱 Fully Responsive Layout
- 🧊 Glassmorphism UI
- 🎨 CSS Variables for easy theming
- ✨ Smooth Animations
- 📂 Project Showcase
- 💼 Resume View & Download
- 📧 Contact Section
- ⚡ Fast & Lightweight

09. About
